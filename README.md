# OtoRisk MVP

Tek sayfalık, maliyetsiz çalışan araç ilanı risk kontrol aracı.

## Nasıl açılır?

`index.html` dosyasını tarayıcıda aç.

## Bu sürüm ne yapar?

- İlan metninden risk kelimelerini yakalar.
- Marka, model, versiyon/motor, yıl ve şehir alanlarını listeden seçtirir.
- Yaşa göre kilometreyi yorumlar.
- Hasar, boya ve değişen bilgisini risk skoruna katar.
- İlandaki çelişkileri yakalar.
- Satıcıya sorulacak kontrol sorularını üretir.

## Para yazan servis var mı?

Hayır. Canlı emsal scraper ve arama API çağrısı kapatıldı. Site analiz sırasında Apify, Tavily veya başka ücretli bir servise istek atmaz.

Bu yüzden bu sürüm fiyatı "pahalı/ucuz" diye kesin söylemez. Fiyat karşılaştırması için aynı motor, yıl, km ve kondisyon ilanları şimdilik manuel kontrol edilmelidir.
